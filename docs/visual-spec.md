# Nodal 视觉规范（visual-spec）

> 目标：让「一张会生长的思维图谱」在浅色和深色下都保持清晰、克制、可长时间阅读。
> 本文与 `frontend/src/index.css` 中的 `--nodal-*` 变量一一对应；改色先改变量，不在组件里写死。

## 1. 品牌

| 项 | 值 |
|---|---|
| 名称 | Nodal |
| Slogan | 思维不再是一条直线 |
| 主色 | `#4060FF` |
| 气质 | 理性、结构感、轻量、不炫技 |
| Logo | 文字标 `Nodal` + 一个分叉节点符号，不另造图形标 |

主色只用于：主按钮、选中态、焦点环、关键数字、当前导航。
不要整页铺主色，深色模式下尤其避免大面积饱和色。

## 3. 字体

| 用途 | 字体 | 回退 |
|---|---|---|
| 英文 | Inter | system-ui, sans-serif |
| 中文 | 思源黑体 SC | PingFang SC, Microsoft YaHei |
| 代码/公式 | JetBrains Mono | ui-monospace, SFMono-Regular, Menlo |

字号阶梯：12 / 13 / 14 / 16 / 20 / 28 / 40。
正文 14px，行高 1.65；画布节点标题 14px/600，正文 13px；页面大标题 28–40px。
代码节点使用等宽字体，开 `font-variant-ligatures: none`，避免公式/代码误读。

## 4. 间距、圆角、阴影

- 间距基数 4px：4 / 8 / 12 / 16 / 20 / 24 / 32 / 48。
- 圆角：控件 8px，卡片 12px，弹窗 16px，节点 12px，标签 999px。
- 阴影只两级：
  - `--nodal-shadow`：卡片/浮层；
  - 选中节点：主色 2px 边框 + 8px 低透明光晕，不叠加多层阴影。
- 画布背景：浅色细点阵 `#dfe3ec`，深色 `#2b303b`，间距 24px；缩放到 <35% 时降低点阵不透明度。

## 5. 布局

### 5.1 应用外壳

- 顶栏 64px：左 Logo + 导航（首页/资源库/广场），右主题切换 + 登录/用户菜单。
- 内容最大宽度 1200px，左右 24px 安全边距；首页可放宽到 1320px。
- 画布页不使用外壳，直接全屏工作台；顶部工具条悬浮，左右面板独立滚动。

### 5.2 画布

- 节点默认尺寸 `248 × 154`，水平/垂直间距 28px（`findFreePosition` 以该尺寸避让）。
- 节点结构：顶部 kind 图标 + 标题；中部内容预览；底部来源徽标/关系标签。
- 用户节点：`surface` 背景 + `border` 边框；
- AI 节点：虚线边框 + 左下 `AI` 徽标；
- 结论节点：左侧 4px 黄色竖条 + 浅黄背景（浅色 `#fff8e1`，深色 `rgba(255,200,87,.12)`）。
- 选中：主色边框 + 轻光晕；多选时显示框选矩形（主色 12% 填充 + 1px 边框）。
- 连线：平滑贝塞尔，1.5px；颜色跟随关系；选中边加 2px 光晕；箭头只在 hover/选中显示。

### 5.3 右侧面板

三个 Tab：画布信息 / Agent 列表 / 知识库挂载；宽 320px，边框分隔，Tab 下划线用主色。
面板内表单控件高 36px，主按钮在底部右对齐；危险操作用反例色描边，不填充大红。

## 6. 组件规范

### 6.1 按钮

| 类型 | 样式 |
|---|---|
| 主按钮 | 主色填充、白字、8px 圆角、高 36–40px |
| 次按钮 | surface 背景、1px border、text 色 |
| 幽灵按钮 | 无背景，hover 时 surface-soft |
| 危险按钮 | 反例色文字/描边，hover 轻填充 |
| 图标按钮 | 32×32，圆角 8，必须有 `aria-label` |

禁用态统一 45% 不透明度，不用灰色文字伪装可点击。

### 6.2 卡片 / 标签

- 卡片：12px 圆角、1px 边框、`--nodal-shadow`；hover 上浮 2px，不放大。
- 画布卡片信息顺序：标题 → 描述 1 行 → 标签 → 节点/连线数 → 更新时间。
- 标签：999px 胶囊，12px 字号，surface-soft 背景；选中标签用主色 12% 背景 + 主色文字。

### 6.3 弹窗 / Toast

- 弹窗遮罩 `rgb(17 19 24 / .55)`，内容最大宽 520px，16px 圆角，标题 18px/600。
- Toast 固定右上，`top: 74px`（避让 64px 顶栏），最多 3 条，宽 ≤360px，圆角 10px。
  - success 左侧 3px 佐证色；error 反例色；info 主色。
  - 自动 3.2s 消失；2 秒内同文案去重；`aria-live="polite"`。

### 6.4 空态

- 画布空态：居中虚线框 + 五种节点按钮（文本/代码/公式/图片/文件），文案「从一个命题开始」。
- 资源库空态：一句解释 + 主按钮「新建画布」；Demo 生成中显示 loading，不显示空白表格。

## 7. 动效

- 时长：hover 120ms，面板/弹窗 180ms，推演节点入场 220ms。
- 缓动：`cubic-bezier(.2,.8,.2,1)`；只动 `opacity/transform`，不动宽高。
- 推演新增节点：淡入 + 从锚点方向 8px 位移；边用 `stroke-dashoffset` 生长。
- 遵守 `prefers-reduced-motion`：关闭位移动画，只保留透明度。

## 8. 可访问性

- 正文/背景对比 ≥4.5:1；次要文字 ≥4.5:1（`--nodal-muted` 已校验）。
- 焦点环：2px 主色 + 2px offset，不只靠颜色表达选中。
- 关系不只靠颜色：边标签显示「推导/反例/佐证/假设」，节点有图标。
- 所有图标按钮有中文 `aria-label`；Toast 不抢焦点；弹窗打开后焦点落在首个输入。
- 键盘：Tab 可达所有控件，Esc 关弹窗，画布内 `Ctrl+Z` 不劫持输入框。

## 9. 响应式

- ≥1200px：三栏（左工具/画布/右面板）；
- 768–1199px：右面板可折叠为抽屉；
- <768px：画布可浏览、节点可点开，但不承诺完整拖拽编辑；顶栏导航折叠为菜单。
- 触控目标最小 40×40px。

## 10. 禁止项

- 禁止紫蓝渐变大面积铺底、玻璃拟态、发光文字；
- 禁止在节点内使用超过 2 种强调色；
- 禁止用颜色单独表达关系/状态；
- 禁止把 emoji 当图标；
- 禁止在浅色主题使用纯黑文字/纯白卡片硬编码。
