# Nodal 视觉规范

## 1. 品牌基础

| 项 | 值 |
|---|---|
| 名称 | Nodal |
| Slogan | 思维不再是一条直线 |
| 英文口号 | Thoughts branch freely. |
| 气质 | 极简、克制、工程感；Linear / Figma 风；不要赛博朋克与花哨渐变 |

## 2. 色板

### 2.1 主色与语义色

| 用途 | 色值 | 说明 |
|---|---|---|
| 主色 Primary | `#4060FF` | 强调、主按钮、推导关系 |
| 反例 Refute | `#FF6B6B` | 反驳、校验者、告警 |
| 佐证 Support | `#36C9A5` | 补充证据、总结者、成功态 |
| 并行 Parallel | `#FFC857` | 并行假设、构建者、提醒 |

### 2.2 中性色

| 用途 | 浅色主题 | 深色主题 |
|---|---|---|
| 页面背景 | `#F7F8FA` | `#111318` |
| 卡片 / 画布底 | `#FFFFFF` | `#1A1D24` |
| 正文主色 | `#1F2937` | `#E5E7EB` |
| 次要文字 | `#6B7280` | `#9CA3AF` |
| 分割线 | `#E5E7EB` | `#2A2E37` |

### 2.3 使用约束

1. 一套界面**最多三种颜色同时出现**（主色 + 一个语义色 + 中性色）。
2. 语义色永远只用于表达语义，不作为装饰。
3. 文字与背景对比度 ≥ 4.5:1。

## 3. 字体

| 场景 | 字体 | 字号 |
|---|---|---|
| 展示标题 | Inter / 思源黑体 SC Bold | 40–64px |
| 页面标题 | Inter / 思源黑体 SC Semibold | 28–32px |
| 正文 | Inter / 思源黑体 SC Regular | 14–15px |
| 辅助说明 | Inter | 12px |
| 代码 | JetBrains Mono | 13px |
| 公式 | KaTeX（Latin Modern） | 自适应 |

字间距：标题 `+0.5px`，正文 `0`，代码 `0`。

## 4. 节点视觉

| 属性 | 规格 |
|---|---|
| 圆角 | 10px |
| 内边距 | 14px |
| 最小尺寸 | 180 × 60 |
| 边框 | 1px `#E5E7EB`（深色 `#2A2E37`） |
| 选中态 | 1px 主色边框 + 4px 主色 12% 外发光 |
| 来源标记 | 用户节点左侧 2px 灰色竖条；Agent 节点左侧 2px 主色竖条 |
| 状态态 | `streaming` 顶部一条 2px 进度光带 |

## 5. 连线

| 项 | 规格 |
|---|---|
| 形态 | 平滑贝塞尔（`smoothstep` 或 `bezier`） |
| 粗细 | 1.5px（选中 2.5px） |
| 颜色 | 跟随关系类型，见 PRD §5.2 |
| 标签 | 居中胶囊，8px 圆角，半透明背景，11px 字 |
| 箭头 | 仅在 `derives` 与 `optimizes` 显示 |

## 6. 间距系统

基准 4px，常用档位：`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64`。
页面外边距 32px，模块间距 24px，元素间距 12px。

## 7. 组件规范

| 组件 | 规格 |
|---|---|
| 按钮 主 | 主色实底，白字，圆角 8px，高 36px |
| 按钮 次 | 透明底 + 1px 中性边框 |
| 输入框 | 圆角 8px，聚焦时 1px 主色边框 |
| 卡片 | 1px 边框，无阴影或极淡阴影，**禁止堆叠多层圆角卡片** |
| 工具提示 | 深色半透明底，11px 白字，圆角 6px |

## 8. 动效

| 场景 | 时长 | 曲线 |
|---|---|---|
| 节点新增 | 220ms | `cubic-bezier(0.2, 0, 0, 1)` |
| 布局重排 | 320ms | 同上 |
| 主题切换 | 200ms | `ease-out` |
| 流式追加 | 逐段落入，无位移 | — |

## 9. 图标

统一使用 IconPark 线性图标，线宽 1.5px，尺寸 16 / 20 / 24。
禁止使用 emoji 表达语义。

## 10. 图片与插画

只用抽象节点 + 连线的构成式画面；深色背景用 `#111318` 加主色发光点。
禁止商务插画（西装握手、齿轮地球、上升箭头小人）。

## 11. 禁止项

1. 禁止圆角矩形卡片堆叠构建层级——用分割线、留白、字号对比。
2. 禁止三等分 / 四等分机械均分构图。
3. 禁止三种以上语义色同屏堆砌。
4. 禁止大面积渐变、玻璃拟态、发光霓虹。
5. 禁止 emoji 出现在任何界面元素中。
