# Nodal 产品需求文档（PRD）

> 版本：v1.0（模块 1–10 收尾后的实现版）
> 定位：无限画布式 AI 思维推演引擎
> Slogan：思维不再是一条直线

## 1. 产品定位

Nodal 把「和 AI 对话」从线性聊天记录，改成一张可自由生长、可分叉、可协作的思维图谱。
用户先放置一个命题，再用推导、反例、佐证、并行假设四类关系扩展；AI 只作为推演助手，在选中节点上增量补充新分支，不覆盖用户已有的判断。

## 2. 要解决的问题

| 痛点 | 传统对话 | Nodal |
|---|---|---|
| 分支容易丢 | 上下文越滚越长，旧分支被淹没 | 每个分支持久化为节点/边 |
| 只能顺序思考 | 一问一答，难以并列比较 | 并行假设、多方案并排 |
| 结论不可追溯 | 只看到最后一段回答 | 从结论沿边回溯到证据/反例 |
| AI 会改掉原意 | 重新生成覆盖前文 | AI 仅新增节点，删除/修改被服务端丢弃 |
| 创作无法复用 | 对话不可分享、不可 fork | 分享链接、Fork 成独立副本、公共广场 |

## 3. 目标用户

- 需要拆解复杂问题的产品/咨询/研究人员；
- 需要比较多个技术方案、保留评审证据的工程师；
- 需要把思考过程沉淀为可复用结构的内容创作者/教师；
- 需要评审他人论证链的团队。

## 4. 产品目标与非目标

### 4.1 目标

1. 用户 3 分钟内能创建第一张有分支的画布；
2. 一次推演能在选中节点旁稳定生成 2–5 个新节点，并保持原图不被破坏；
3. 任意结论节点都能沿关系边回溯到支撑/反驳证据；
4. 画布可通过链接只读分享，或 Fork 为他人独立副本；
5. 新用户注册后立刻看到两个可操作的 Demo，而不是空白页。

### 4.2 非目标（当前版本）

- 不做多人实时协同光标/CRDT；
- 不做移动端完整编辑体验（仅自适应布局）；
- 不做计费、团队空间、企业 SSO；
- 不做通用聊天机器人入口；
- 不做公网可用的无隔离代码执行（REPL 受宿主能力约束）。

## 5. 核心概念与数据模型

### 5.1 节点 NodalNode

```ts
{
  id: string                 // 画布内唯一
  type: 'nodal'              // ReactFlow 自定义节点类型
  position: { x: number, y: number }
  data: {
    kind: 'text' | 'code' | 'formula' | 'image' | 'file'
    label: string
    text?: string
    code?: string
    language?: string
    formula?: string
    url?: string
    fileName?: string
    source: 'user' | 'agent'
    ai_generated?: boolean
    agent_id?: number
    agent_name?: string
    status?: 'normal' | 'conclusion'
    color?: string
  }
}
```

### 5.2 关系 NodalEdge

```ts
{
  id: string
  source: string
  target: string
  type: 'relation'
  data: { relation: 'derive' | 'counter' | 'evidence' | 'hypothesis', label?: string }
}
```

### 5.3 画布 Canvas

- `id / owner_key / title / description`
- `nodes / edges / viewport / tags`
- `is_public / share_mode`
- `forked_from / node_count / edge_count`
- `published_at / like_count / comment_count`
- 审计：`created_at / updated_at / deleted_at`

约束：单图 ≤5MB、≤2000 节点、≤5000 边、≤10 标签、标签 ≤20 字、标题 ≤120 字；边端点必须存在；只有所有者可编辑。

## 6. 信息架构

```text
/                 首页：价值主张 + 关系类型 + 最新广场
/library          资源库：我的画布 / 知识库 / Agent 模板
/square           广场：公开画布、标签筛选、点赞评论
/canvas/:id       画布工作台
/share/:token     分享只读页（当前占位）
```

## 7. 功能需求

### 7.1 账号与身份

- 邮箱注册/登录、JWT、昵称/头像；
- 游客自动获得临时身份（`g:<gid>`），可创建私有画布；
- 游客升级登录后画布不自动迁移（当前边界）；
- 仅注册用户可用：Agent、知识库、推演、REPL、发布/点赞/评论、分享链接。

### 7.2 画布与节点

- 无限画布平移/缩放/框选/多选；
- 创建文本、代码、公式、图片、文件五类节点；
- 拖拽连线并选择四种关系；
- 节点编辑器：Markdown、Monaco、KaTeX、图片预览/文件信息；
- 撤销/重做（上限 60 步）；
- 自动保存（1.4s debounce）与 `Ctrl+S`；
- 节点视觉区分用户/AI/结论；边颜色跟随关系。

### 7.3 AI 推演

- 入参：选中节点 ID 列表 + Agent；
- 输出：SSE `start → sources? → node* / edge* → warning* → done`；
- 硬约束：只能新增，`delete/update` 丢弃并计入 `skipped`；
- 新节点自动放到空闲位置，前端增量渲染；
- 单画布并发推演互斥，单次节点数可配（默认 50）。

### 7.4 Agent 与模型

- Agent 模板：名称、描述、system prompt、model_id；
- 模型目录 + 统一适配器（mock / OpenAI 兼容 / Anthropic / 通义千问等）；
- 用户可保存自有 API Key，AES-256-GCM 加密，读接口只回尾号；
- 无 Key 时回退 mock，本地可完整体验。

### 7.5 知识库与 RAG

- 上传 PDF/DOCX/HTML/TXT/MD；
- 解析→清洗→按字符窗口切片→Embedding→pgvector（或 SQLite/MySQL JSON 兜底）；
- 画布挂载为进程内临时关联，不持久化；
- 推演只召回当前画布已挂载文件的片段。

### 7.6 广场、分享与 Fork

- 发布/下架公开画布；
- 广场分页、标签/关键词筛选、latest/hot 排序；
- 点赞切换、评论/删除评论；
- 分享链接 `read | fork` 权限、可过期、可停用；
- Fork 生成独立私有副本，保留 `forked_from`。

### 7.7 REPL 沙箱

- Python / Shell 会话，WebSocket 流；
- 30s 超时、内存/磁盘配额、禁网络出站、禁持久化；
- 代码节点「运行」拉起终端并回显；
- 无内核隔离能力时明确报 `7001`，不降级为无限制执行。

### 7.8 Demo 与引导

- 新用户自动创建 2 张 Demo：辩论推演、代码方案对比；
- 空资源库兜底补种，幂等；
- 画布空态提供五种节点创建入口。

## 8. 权限矩阵

| 能力 | 游客 | 注册用户 | 所有者 |
|---|---|---|---|
| 创建/编辑自己的画布 | ✅ | ✅ | ✅ |
| 读取公开画布 | ✅ | ✅ | ✅ |
| 编辑他人画布 | ❌ | ❌ | — |
| Fork 可读画布 | ❌ | ✅ | ✅ |
| 推演/知识库/Agent/REPL | ❌ | ✅ | ✅ |
| 发布/点赞/评论 | ❌ | ✅ | ✅ |
| 分享链接创建 | ❌ | ✅ | ✅（自己的画布） |

## 9. 非功能需求

- 首屏 ≤2s（本地）；画布 chunk 懒加载；
- SSE 断线可见失败，不静默丢结果；
- 所有写接口幂等/可重试语义明确（推演互斥、种子幂等、分享复用）；
- 错误码稳定分段，前端不解析文案；
- 数据隔离按 `owner_key`；删除为软删除；
- 安全：JWT、密钥加密、CORS 白名单、上传类型/体积限制、沙箱隔离。

## 10. 验收标准（当前版本）

- [x] 注册后资源库出现 2 张 Demo，各 6 节点 6 连线；
- [x] 画布五类节点可创建、编辑、连线、撤销重做；
- [x] 推演只新增，不删改已有节点；
- [x] 刷新后画布内容保持；
- [x] 分享链接可复制，Fork 生成副本；
- [x] 知识库上传/挂载/RAG 检索闭环；
- [x] 广场列表、点赞、评论可用；
- [x] 前端异常有 toast/错误页，不白屏；
- [x] 生产配置、迁移、部署、CI 有文档/脚本。

## 11. 指标（上线后观察）

- 新用户 24h 内创建 ≥1 张非 Demo 画布的比例；
- 首次推演成功率、平均新增节点数；
- 画布 7 日留存与 Fork/分享转化；
- 推演中断率、SSE 首帧时延；
- 广场发布→浏览→Fork 漏斗。

## 12. 风险与边界

| 风险 | 现状 | 后续 |
|---|---|---|
| 大画布性能 | 2000 节点上限 + chunk 懒加载 | 节点虚拟化、分片渲染 |
| 分享只读页 | 占位 | 独立只读渲染器 + 权限水印 |
| 多人协同 | 未实现 | 引入 CRDT/OT 与在线状态 |
| 容器化 REPL | 宿主权限受限 | Firecracker + KVM 独立节点池 |
| 数据模型 | 多列 JSON | 统一 `content_json` 单字段 |
